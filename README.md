# TP1 - Mi Portfolio en React

Portfolio personal desarrollado como Trabajo Práctico N°1 para la materia Programación (UTN FR Tucumán).

## Descripción

Sitio web tipo portfolio que presenta información personal, habilidades y proyectos, desarrollado con React y Vite.

## Tecnologías utilizadas

- React
- Vite
- CSS

## Estructura del proyecto

- `Header` - Barra de navegación
- `Hero` - Sección de presentación principal
- `About` - Información sobre mí
- `Skills` - Habilidades técnicas
- `Projects` - Proyectos personales
- `Footer` - Pie de página

## Instalación y uso

1. Cloná el repositorio:
```bash
git clone https://github.com/ignaciorivass/Tp1-react-portfolio-Rivas-Ignacio.git
```

2. Instalá las dependencias:
```bash
npm install
```

3. Corré el proyecto en modo desarrollo:
```bash
npm run dev
```
